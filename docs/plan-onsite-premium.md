## 0. 结论摘要（TL;DR）

1. **范围**：第一版只做「纳指 100 + 标普 500」的场内份额，共 **18 只 = 16 只 ETF + 2 只 LOF**，逐只已验证价格、参考净值、成交额可取。主题类（纳指科技 159509、纳指生物科技 513290）留第二批。
2. **主指标是溢价率**，但 QDII 有美股时差，必须拆成**两个口径**同时展示，否则数字会误导：
   - `溢价率（实时口径）`＝ 现价 ÷ 最新公布参考净值 − 1，随时可得，但含隔夜美股涨跌偏差；
   - `溢价率（校准口径）`＝ 某交易日收盘价 ÷ **同一估值日**单位净值 − 1，隔 1–2 个交易日才能算，是真实溢价的基准值。
   实测 2026-10-30 收盘对 10-29 净值，18 只平均 +9.4%（区间 +3.7%~+16.8%），高度一致，无法用单一数字区分「系统性净值滞后」和「真实溢价」——这正是必须双口径的原因。
3. **数据源**：沪深交易所官方行情（A 级，已实测可用）为主；东方财富公开接口做净值日期、申购状态与交叉校验（B 级）；集思录匿名只返回前 20 行，**不作为依赖**。
4. **落点**：现有看板新增「场内折溢价」板块 + 每只场内基金详情页；小程序同步；新增工作日 15:05 收盘抓取。**不做告警**（按本次确认）。
5. **工作量**：约 4–5 个工作日，拆 5 个里程碑；失败关闭、双源比对、D 级不覆盖上次可信值等既有规则全部沿用。

## 1. 背景与目标

现有项目只监控**场外份额**的申购状态、每日额度和费率（`rows` + `fees` + `holdings`）。场内 ETF/LOF 是可以直接买卖的另一套决策：

- 场外联接基金限额/暂停时，资金会挤向场内，场内价格常出现**溢价**；
- 溢价高时买入 = 用高于净值的价格买入底层资产，即使指数不跌也可能亏损；
- QDII 场内有额度限制、申购常暂停，套利机制不顺畅，溢价可以持续多日。

第一版目标（仅此，不扩散）：

1. 每个交易日给出 18 只场内基金的**收盘溢价率**（含净值日期与口径）；
2. 给出盘中可得的**实时参考溢价率**，并在页面明确它不等于真实溢价；
3. 每条数据保留**来源、时间、可靠性等级**，抓取失败时显式降级，不猜、不沿用旧值冒充当前值；
4. 在看板上与场外额度并列可查，但**不与场外指标混合、不相加**。

非目标（第一版明确不做）：套利收益测算、IOPV 自算、「溢价率反推申购状态」、自动交易、溢价率阈值告警（本次确认不做，但阈值配置保留，后续可开启）。

## 3. 指标口径（本计划最关键部分）

### 3.1 定义

```
溢价率（实时口径，premiumLive）
  = 最新成交价 / 最新参考净值 − 1

溢价率（校准口径，premiumCalibrated）
  = 估值日 D 的收盘价 / 估值日 D 的单位净值 − 1     （D 为已同时拿到收盘价与该日净值的最近交易日）
```

- **参考净值优先级**：交易所发布的参考净值/IOPV（沪市 `iopv`、深市 ETF `netValue`、深市 LOF `prevNetValue`）> 最新公布单位净值（东方财富，带净值日期）。
- **校准口径是本项目的“基准值”**：同一估值日的收盘价配同一估值日的净值，剔除美股隔夜涨跌的错配，等价于集思录/市场常用的“溢价率”口径，但用已公布的**实际净值**而非预估。
- **实时口径是“读数”**：随时可得，但 QDII 的净值天然滞后（美股 T-1 收盘、净值 T+1 公布），当天净值往往还没出，所以数字偏大或偏小都正常，页面必须并列净值日期，不允许单独展示一个光秃秃的百分比。

### 3.2 为什么必须双口径（实测证据）

2026-10-30（周五）收盘价 ÷ 2026-10-29 单位净值，18 只全部为正溢价，平均 **+9.4%**，最低 +3.7%（161125）、最高 +16.8%（159501）。全部标的（含标普 500 和 LOF）溢价方向、量级高度一致，更像「净值比价格滞后一个美股交易日」的系统性偏差，而不是 18 只产品同时出现套利空间。

结论：只给一个百分比无法支撑决策。v1 展示「校准口径（主）+ 实时口径（辅，标注时差）」，并在详情页用一句话解释两者差异。

### 3.3 显示规则

- 主数值：校准口径（最近可校准日），标注「校准日 D」；
- 副数值：实时口径，标注「净值日期」与「含美股时差」；
- 若校准值当天算不出（净值未公布），主数值位显示「待净值公布」，**不拿实时口径顶替主数值**；
- 数值保留 2 位小数；涨跌色带按当日截面分位数（见 3.4），不使用固定的“红绿涨跌”语义。

### 3.4 阈值与色带（第一版先自适应，避免拍脑袋）

- 实时/校准值均先按**当日全样本分位数**着色：`< p25` 折价区 / `p25–p75` 常态 / `p75–p90` 偏高 / `> p90` 高；
- 另保留固定警示线 `highPremiumPct`（默认 **5%**，写入 config，第一版只用于文案标记与排序，不触发通知）；
- 累计 5–10 个交易日后，用实际分布校准固定线，再决定是否开启告警。

> 理由：本次实测溢价分布（3.7%–16.8%）与日常经验值差异很大，直接写死“3% 偏高”会立刻失真。阈值必须配置化并经过数据校准。

### 3.5 异常与失败关闭（沿用项目规则）

| 情形 | 处理 |
|---|---|
| 官方行情与本项目净值源都失败 | `premiumLive = null`，`reliability = D`，状态 `unknown`；保留上一条 A–C 级快照但标记 `carriedForward: true` 与原始 `observedAt` |
| 交易所参考净值与净值源偏差 > 0.5% | 视为数据异常：不展示溢价数值，降 D，附告警 |
| 净值日期比价格日滞后 > 1 个交易日 | 实时口径降 C 并标注「净值滞后 N 个交易日」；校准口径不参与 |
| 当日无成交（`volume = 0`）或停牌 | 不使用该价格，降 D/unknown |
| 净值缺失、拆分/分红导致分母异常 | 降 D，不猜 |
| 只有第三方（东方财富）可用 | 降 B/C 并注明「官方行情不可用，使用第三方公开行情」 |
| 节假日/美股休市 | 正常抓取，但校准口径标注“非交易日”、在摘要计数中排除 |

## 4. 数据源与可行性验证（已实测）

### 4.1 官方行情（目标 A 级）

**上交所**（仅 HTTP，需加入白名单，**已验证**）：

```
GET http://yunhq.sse.com.cn:32041/v1/sh1/snap/{code}?select=name,last,preclose,iopv,open,high,low,volume,amount
→ {"code":"513100","date":20261030,"time":162902,
   "snap":["纳指ETF",2.2390,null,1.9660,2.2410,2.2580,2.2340,202945148,456043207]}
```

- `last` = 最新价/收盘价，`iopv` = 基金份额参考净值（QDII 场内参考净值），`volume/amount` = 成交量/成交额；
- 不需要 Referer，项目 UA 可用；**HTTPS 端口不通（TLS 协议告警），必须走 HTTP** → 按 AGENTS.md 走官方 HTTP 白名单例外并记录理由；
- 非文档化内部接口，存在变更风险（见风险节）。

**深交所**（HTTPS 可用，**已验证**）：

```
GET https://www.szse.cn/api/market/ssjjhq/getTimeData?marketId=1&code=159941
→ {"datetime":"2026-10-30 15:30","data":{
     "name":"纳指ETF广发","now":"1.649","close":"1.690","netValue":"1.471",
     "prevNetValue":null,"amount":1225154601.647,"marketTime":"2026-10-30 15:30:00",
     "piciopv":[["09:30",1.471],...]}}
```

- ETF：`netValue` = 参考净值（与 T-1 单位净值一致）；LOF：`netValue` 为空、`prevNetValue` = 前一日净值；
- 另有 `picupdata/picdowndata/piciopv/picavgprice` 分时序列（约 30KB/只），第一版不存，后续可做分时图；
- 返回 `close` 为昨收、`now` 为最新价，15:30 后 `now` 即收盘价。

### 4.2 交叉校验与净值日期（B 级）

- 价格：`https://push2.eastmoney.com/api/qt/stock/get?secid={1|0}.{code}&fields=f43,f59,f60,f57,f58`（`f43` 需按 `f59` 小数位换算；实测 `f59=3` 即 ÷1000）；
- 净值/净值日期/申购状态：`https://api.fund.eastmoney.com/f10/lsjz?fundCode={code}&pageIndex=1&pageSize=2`，**必须带 Referer**（实测无 Referer 返回 `ErrCode:-999`）；
- 上交所参考净值与东财净值实测偏差约 0.01–0.02%，0.5% 的异常阈值有足够余量；
- 东方财富 `push2` 有偶发 `Remote end closed connection`（实测 19 次中约 14 次偶发、重试即成功）→ 必须有重试与降级，不能单源依赖。

### 4.3 不作为依赖

- **集思录**：`https://www.jisilu.cn/data/qdii/qdii_list/E` 匿名只返回 `rows` 20 条，`warn` 明示「共有 55 条记录，游客仅显示前 20 条，请登录查看完整列表数据」；`discount_rt`（溢价率）匿名下为空。**不抓取、不作为数据源**，只允许人工抽查校准口径。
- 不访问任何登录接口、不保存 Cookie。

- `state.json` 额外保存 `closeByDate`（最近 5 个交易日各代码收盘价）用于校准口径。

## 附录 B：页面文案草稿（口径说明）

- `校准溢价`：同一估值日的收盘价 ÷ 当日单位净值 − 1；净值公布后计算，通常滞后 1–2 个交易日。
- `实时溢价`：现价 ÷ 最新公布参考净值 − 1；QDII 净值含美股时差，**不是**真实溢价，也不代表可以套利。
- `净值日期`：溢价率分母的估值日；与“价格日期”不一致时页面会明确标注。
- `数据来源`：交易所公开行情 + 公开净值，非登录后下单验证；仅供核验，不构成投资建议。

## 附录 C：实施备注（2026-11-01）

- **GitHub Actions 网络实测**：上交所 `yunhq.sse.com.cn` 官方行情在海外 runner 可用（沪市 7 只 A 级）；深交所 `www.szse.cn` 官方接口在 runner 上全部 `ETIMEDOUT`（深市 11 只），因此深市按设计降级为东方财富公开行情（B 级），页面显示“交易所官方行情不可用”。若后续找到可达的官方替代入口，只需替换 `src/onsite` 的官方请求，不影响数据契约。
- **校准分子口径调整**：最初限制只保存官方收盘价，会导致深市 11 只永远无法计算校准溢价。实施时改为“官方优先、第三方兜底”：交易所不可达时保存第三方公开行情收盘价，但该条 quote 已降为 B 级，校准结果继承该等级，不静默升为 A。
- **第三方回退价格的时间戳**：东方财富 push2 的 `f86` 为最后成交时间；用它生成 `priceDate/priceAt`，避免用抓取时间（周末/节假日会错误标注价格日期并污染 `closeByDate`）。
- **时区**：小程序时间统一按 UTC+8 显示，避免设备/CI 时区导致输出不一致。
